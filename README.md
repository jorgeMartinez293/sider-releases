# sider-releases

Release assets and the Sparkle appcast for [jorgeMartinez293/sider](https://github.com/jorgeMartinez293/sider).

- `Releases/` — this repo's GitHub Releases hold the `.zip`/`.dmg`/`.delta` assets.
- `appcast.xml` (on `main` and `gh-pages`) — the Sparkle feed, served via GitHub Pages from `gh-pages`.

Populated automatically by `scripts/ship.sh` in the main repo. Nothing here is meant to be edited by hand.
